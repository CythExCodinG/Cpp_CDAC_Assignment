## 🛠️ How to Run

### 1️⃣ Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/CPP-CDAC-ASSIGNMENT.git
```

### 2️⃣ Navigate into the project

```bash
cd CPP-CDAC-ASSIGNMENT
```

### 3️⃣ Compile a program

```bash
g++ program.cpp -o program
```

### 4️⃣ Run

```bash
./program
```

For Windows:

```bash
program.exe
```
