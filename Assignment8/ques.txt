

1. Write a C++ program using inheritance, runtime polymorphism and templates to calculate parking charges for different types of vehicles.

Parking Types
Vehicle Type: Car

Fixed parking charge: Rs. 100 for first 3 hours

Beyond 3 hours: Rs. 30 per hour

No discount available.

Vehicle Type: Truck

Fixed parking charge: Rs. 200 for first 2 hours

Beyond 2 hours: Rs. 50 per hour

Discount available: Code TRUCK50 gives Rs. 50 off

Program Requirements

Use abstract base class Vehicle with a pure virtual function calculateCharge().

Create derived classes Car and Truck.

Use runtime polymorphism to handle both vehicle types dynamically.

Implement a static data member to count how many parking receipts are generated.

Use a function template to validate the discount code.

Use an inline function to compute extra parking charges.

Input Validation

Parking hours must be positive.

If vehicle type is invalid, prompt again.

Sample Input / Output
Sample Input 1
Enter type of Vehicle (C for Car, T for Truck): C
Enter parking hours: 5
Expected Output
Vehicle type = Car
Extra charge = Rs. 60
Total Parking Charge = Rs. 160
Receipts generated so far: 1

Sample Input 2
Enter type of Vehicle (C for Car, T for Truck): T
Enter parking hours: 5
Enter discount code if available (or press Enter to skip): TRUCK50
Expected Output
Vehicle type = Truck
Extra charge = Rs. 150
Total Charge after discount = Rs. 300
Receipts generated so far: 2



2. Write a C++ program for a Vehicle Registration System using inheritance, runtime polymorphism, templates, and file handling.

1) Abstract Base Class: Vehicle

Properties: RegistrationNumber, ModelName, Manufacturer, Year.

Pure virtual function: displayInfo().

Validation: Year should be between 2000 and the current year.

2) Derived Classes
Car

Adds property: FuelType

Bike

Adds property: EngineCapacity

3) Other Requirements

Use runtime polymorphism (Vehicle* or smart pointers) to manage both Car and Bike objects.

Use a template function to validate the input year.

Use a static data member in Vehicle to count how many vehicle records are created.

Use an inline function to format and return the vehicle display string.

Store vehicle objects into a binary file, then read them back and display the records.

Implement exception handling for invalid inputs (e.g., empty registration number, invalid year).

Sample Input
Enter number of vehicles: 2

Enter type of vehicle (C for Car, B for Bike): C
Enter Registration Number: MH20AB1234
Enter Model Name: Swift
Enter Manufacturer: Maruti
Enter Year: 2018
Enter Fuel Type: Petrol

Enter type of vehicle (C for Car, B for Bike): B
Enter Registration Number: MH20XY5678
Enter Model Name: Pulsar
Enter Manufacturer: Bajaj
Enter Year: 2020
Enter Engine Capacity: 150cc
Expected Output (after reading from file)
RegNo: MH20AB1234, Model: Swift, Manufacturer: Maruti, Year: 2018, FuelType: Petrol
RegNo: MH20XY5678, Model: Pulsar, Manufacturer: Bajaj, Year: 2020, EngineCapacity: 150cc
---------------------------------------------------------------------------------------
Total Vehicles stored: 2
